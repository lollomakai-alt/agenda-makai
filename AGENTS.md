# Istruzioni progetto — Agenda Makai

## Letture obbligatorie prima di ogni intervento
- Leggi le istruzioni generali Codex in `~/.codex/AGENTS.md`.
- Leggi questo file e poi [stato e attività di Agenda](MAKAI_AGENDA_STATO_E_TODO.md) e [roadmap comune dell'ecosistema](../MAKAI_ECOSISTEMA_STATO_E_ROADMAP.md).
- Controlla `git status` e preserva ogni modifica preesistente.

## Confini
- Segui le protezioni generali: nessuna modifica a codice, database o configurazione produzione durante attività documentali; niente commit, push o deploy senza richiesta esplicita.
- Preserva prenotazioni e cronologia. Non applicare SQL o mutazioni live sulla base di sola documentazione.
- Alla fine aggiorna [stato e attività di Agenda](MAKAI_AGENDA_STATO_E_TODO.md) con evidenze e limiti, usando le quattro categorie di stato definite nelle istruzioni generali.
